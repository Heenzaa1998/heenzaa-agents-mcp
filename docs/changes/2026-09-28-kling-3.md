# generate_video รองรับ Kling 3.0

- **วันที่:** 2026-09-28
- **Design doc:** `docs/design/2026-09-28-kling-3.md`
- **Commit / PR:** branch `feat/kling-3`

## เปลี่ยนอะไร

- `generate_video` มีพารามิเตอร์ `model` (`kling-3.0` เป็นค่าเริ่มต้น หรือ `kling-2.6`)
- ของ Kling 3.0 (`kling-3.0/video`):
  - `duration` 3–15 วินาที
  - `mode` std/pro/4K
  - `end_image_url` (เฟรมสุดท้าย)
  - `elements` ผูกตัวละครหรือของกับภาพอ้างอิงได้สูงสุด 3 ตัว อ้างในพรอมต์ด้วย `@name`
- Kling 2.6 ทำงานเหมือนเดิม ถ้าส่งตัวเลือกของ 3.0 มาให้ 2.6 schema จะปฏิเสธพร้อมบอกเหตุผล
- ตรวจว่าทุก element ถูกอ้างถึงในพรอมต์ และ `end_image_url` ต้องมาคู่กับ `image_url`
- ประวัติบันทึกรุ่นที่ใช้จริง (รวมตอน start ล้มด้วย)

## ทำไม

ทำซีรีส์ที่มีตัวละครหลายตัว ต้องการให้หน้าตัวละครไม่เพี้ยนระหว่างขยับ และความยาวคลิปตรงกับบท

## แก้ไขหลังใช้จริง (fix/kling-3-elements)

ตอนใช้งานจริงครั้งแรก KIE ปฏิเสธ 2 ครั้ง ด้วยกฎที่เอกสารไม่ได้เขียนไว้:
1. `element_input_urls must contain between 2 and 4 images` — ตอนแรก schema ให้ใส่ 1–4 ภาพ แก้เป็น 2–4 ภาพ
2. `Image aspect ratio must be between 1:2.5 and 2.5:1` — ภาพอ้างอิงห้ามเป็นแถบยาว ใส่ไว้ใน description ของพารามิเตอร์แล้ว
   (schema ตรวจขนาดภาพจาก URL ไม่ได้)

นอกจากนี้ `kie_create_failed` เดิมไม่บอกเหตุผล ต้องยิง KIE ตรงๆ ถึงจะเห็น
ตอนนี้ error ส่ง `code`/`msg` ของ KIE กลับมาด้วย เช่น `KIE createTask did not return a taskId. 422 …`

ครั้งที่ 3 ใช้ภาพอ้างอิง 3 ภาพ (หน้าตรง/เฉียง/หน้าใกล้ ตัดจาก character sheet) ผ่าน แต่งานแรกล้มที่ฝั่ง KIE
ด้วย `500 Internal Error` (ไม่เสียเครดิต) ส่งซ้ำแล้ว KIE เริ่มสร้างคลิปได้
