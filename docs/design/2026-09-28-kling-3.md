# generate_video รองรับ Kling 3.0

- **วันที่:** 2026-09-28
- **สถานะ:** approved
- **Change record:** `docs/changes/2026-09-28-kling-3.md` (เติมเมื่อทำเสร็จ)

## ปัญหา

`generate_video` ใช้ได้แค่ Kling 2.6 (5 หรือ 10 วินาที) งานซีรีส์คลิปสั้นมีตัวละครหลายตัว
จุดอ่อนหลักของ 2.6 คือหน้าตัวละครเพี้ยนระหว่างขยับ ต้องเจนซ้ำหลายเทค
KIE มี `kling-3.0/video` แล้ว มีข้อดีคือ
- ผูกตัวละครด้วยภาพอ้างอิง (`kling_elements` สูงสุด 3 ตัว)
- กำหนดภาพเฟรมแรกและเฟรมสุดท้ายได้
- ความยาว 3–15 วินาที
- mode std / pro / 4K

## ขอบเขต

**อยู่ในขอบเขต:**
- พารามิเตอร์ `model` (`kling-3.0` | `kling-2.6`) ค่าเริ่มต้น **kling-3.0**
- ของ Kling 3.0:
  - `duration` "3"–"15"
  - `mode` (std/pro/4K ค่าเริ่มต้น std)
  - `end_image_url` (เฟรมสุดท้าย)
  - `elements` (สูงสุด 3 ตัว แต่ละตัวมี `name`, `description`, `image_urls` 1–4 ภาพ อ้างในพรอมต์ด้วย `@name`)
- Kling 2.6 ทำงานเหมือนเดิม: 5/10 วินาที ไม่มี mode, end frame หรือ elements (ถ้าส่งมา schema ปฏิเสธพร้อมข้อความชัดเจน)
- `get_task_status` ใช้ได้กับทั้งสองรุ่น (KIE jobs API เดียวกัน) ความยาวคลิปอ่านจาก `param.input.duration` ได้เหมือนเดิม
- บันทึกรุ่นที่ใช้จริงลงประวัติ (`kling-3.0/video` หรือ `kling-2.6/...`)

**ไม่อยู่ในขอบเขต:**
- multi-shot ในคลิปเดียว (`multi_shots`/`multi_prompt`) กติกาเรื่องผลรวมความยาวยังไม่ชัดในเอกสาร เก็บไว้ทำภายหลัง
- แก้ปัญหาภาพหมดเวลา (image task timeout) จะแยกเป็นงานถัดไป

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย |
| --- | --- | --- |
| A: เพิ่ม `model` ใน `generate_video` ค่าเริ่มต้น 3.0 | tool เดียว ได้ของใหม่ทันที | ผู้เรียกเดิมที่ไม่ระบุรุ่นจะได้ 3.0 ซึ่งราคาต่อวินาทีสูงกว่า |
| B: แบบ A แต่ค่าเริ่มต้น 2.6 | ไม่เปลี่ยนพฤติกรรมเดิม | ต้องจำใส่ `model` ทุกครั้งถึงจะได้ของดี |
| C: tool ใหม่ `generate_video_v3` | ไม่แตะของเดิม | tool ซ้ำ ทำให้สับสน |

## ทางที่เลือก

**A** — ผู้ใช้หลักคือเจ้าของ repo คนเดียว และต้องการ 3.0 เป็นค่าหลัก ส่วน description ของ tool
บอกไว้ว่า 2.6 ถูกกว่าและยังเลือกใช้ได้

## ความเสี่ยง

- ราคา 3.0 บน KIE ยังไม่ได้ยืนยัน เว็บภายนอกบอก std ประมาณ $0.07/วินาที เครดิตที่ใช้จริงบันทึกใน
  `generations.credits` อยู่แล้ว ต้องดูจากงานแรก
- ขนาดภาพอ้างอิงต่อ element ไม่ได้ระบุในเอกสาร KIE ตั้งเพดานไว้ที่ 4 ภาพ ถ้า KIE ปฏิเสธจะเห็นใน error

## การทดสอบ

- unit: schema (ค่าเริ่มต้น, กฎของ 2.6, elements, end frame), service ส่งพารามิเตอร์ตามรุ่นและบันทึกรุ่นถูก
- บน dev: `tools/list` แสดงตัวเลือกใหม่ และส่งค่าที่ผิดกฎแล้วถูกปฏิเสธ (ไม่ใช้เครดิต)
- ทดสอบจริง 1 คลิป (EP01) เพื่อดูราคาจริง
