## ทำไม

ผู้ดูแลถามว่าควรทำคลิป AI แนวไหน รีโปนี้มี tool สร้างภาพ (GPT Image) และวิดีโอ (Kling 2.6)
อยู่แล้ว การรู้ว่าแนวไหนมีคนติดตามจริงและแนวไหนกำลังถูกแพลตฟอร์มลงโทษ ช่วยตัดสินใจว่าจะ
ต่อยอด tool ไปทางไหน (เช่น รักษาตัวละครข้ามตอน) และแนวไหนไม่ควรลงแรง

เก็บไว้ใน `docs/research/` แยกจาก `design/` และ `changes/` เพราะไม่ใช่แผนของงานโค้ดชิ้นใด
แต่เป็นข้อมูลอ้างอิงที่ design doc ในอนาคตจะลิงก์กลับมาได้
